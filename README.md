# kokugo-app

共通テスト国語の問題（縦書き）に、マーカーを引いて指摘メモを付けるアプリです。
ビルドは不要で、`index.html` をブラウザで開けば動きます（Android の Chrome 向け。GitHub Pages などに置いて開く想定）。

## 機能

| 機能 | 内容 |
|---|---|
| マーカーモード | 「マーカー」ボタンで切り替え。指でなぞった文字に色が付く。モード中は画面がスクロールせず、選択肢をタップしても取り消し線は付かない（画面を動かしたいときは2本指で動かす） |
| 色 | 黄＝重要、赤＝ダメな部分・引っかけ、青＝根拠。「消す」でなぞった範囲を消す |
| 対象 | 設問文・選択肢・図表の説明文 |
| 指摘メモ | マーカーモードでマーカーをタップするとメモ入力。よく使う言葉はボタンで入れられる |
| 一覧 | 「一覧」で、そのページのマーカーとメモを 設問→選択肢①→②… の順に表示。「本文で見る」でその場所へ移動 |
| 消去法 | 通常モードで選択肢をタップすると取り消し線（もう一度で解除） |
| 保存 | ページごとに localStorage に自動保存 |
| PDF出力 | ⋯ →「PDFに出力」。A4縦書きでマーカーの色付き。指摘メモの一覧を別ページに付けるか選べる |

## 文字の位置の付け方

- 位置は**区画**ごとに 0 から数える。区画は `q`（設問）、`c1`〜`c4`（選択肢）、`f1`…（図表の説明文）。
- 1文字を1つの `<span data-i="n">` にする。文字は `Intl.Segmenter` の書記素単位なので、「𠮟」などの途中では切れない。
- 2桁までの半角数字（「18」など）は縦中横の1文字として数える。ルビと解答番号の四角は数えない。
- 指の位置は `elementFromPoint` で `span` を探して決めるので、縦書きでも必ず文字の境目でそろう。

保存の形（キー：`kokugo-marks:<問題セットID>:<ページID>`）:

```json
{
  "version": 1,
  "segHash": { "c2": "a91f03c2" },
  "marks": [
    { "id": "m…", "seg": "c2", "start": 66, "end": 82, "color": "red",
      "memo": "本文に書いていない", "createdAt": 1793495013537 }
  ],
  "struck": [1]
}
```

- `start` はその文字を含み、`end` は含まない。
- 1文字に付く色は1つだけ。違う色を重ねると新しい色で上書きし、同じ色が重なるか隣り合うと1つにまとめる。
- `segHash` は本文のハッシュ。問題文を直して位置がずれたおそれがあるときは、画面に警告が出る。

## 問題データの形

サンプルは `data/sample.js` に入っています（第2問 問2〜問6）。ほかの問題は、⋯ →「問題を読み込む（JSON）」で次の形の JSON ファイルを読み込めます。

```json
{
  "id": "no3-dai1",
  "title": "No.3 第1問 現代文",
  "pages": [
    {
      "id": "p5",
      "folio": 5,
      "label": "問1",
      "question": "傍線部Ａ「……」とあるが、……**適当でないもの**を、次の①〜④のうちから一つ選べ。解答番号は[[1]]。",
      "choices": ["……", "……", "……", "……"],
      "figures": [{ "caption": "図1　……", "image": "data:image/png;base64,…" }]
    }
  ]
}
```

文中の書き方は次のとおりです。

- `{毅然|きぜん}`：ルビ
- `**…**`：太字
- `__…__`：傍線
- `[[14]]`：解答番号の四角

## 動作確認の手順（Android の Chrome）

1. **マーカーを引く**
   1. `index.html` を開く。問2（23ページ）が縦書きで表示される。
   2. 上の「マーカー」を押す。ボタンが黒くなり、紙面が黒い枠で囲まれる。
   3. 「ダメ」（赤）を選び、選択肢②の「毅然とした中にも老いを感じさせる」を指でなぞる。なぞっている間は画面がスクロールせず、指を離すと赤い色が付く。
   4. 「重要」（黄）を選び、設問の「最も適当」をなぞる。
   5. マーカーモードのまま選択肢①をタップしても、取り消し線が付かないことを確かめる。
2. **メモを付ける**
   1. 赤く塗った部分を（なぞらずに）タップする。下からメモの入力欄が出る。
   2. 「本文に書いていない」と入力するか、同じ言葉のボタンを押して「保存」を押す。
   3. マーカーの終わりに黒い点が付く。
   4. 「一覧」を押し、「設問　最も適当」→「選択肢②　毅然とした…　本文に書いていない」の順に並ぶことを確かめる。「本文で見る」を押すと、その場所が光る。
3. **再読み込みしても残る**
   1. ブラウザを再読み込みする（またはタブを閉じて開き直す）。
   2. 同じページが開き、赤と黄色のマーカー、メモの黒い点、一覧の内容がそのまま残っていることを確かめる。
4. （おまけ）**消しゴムとPDF**
   1. マーカーモードで「消す」を選び、赤い部分の途中をなぞると、そこだけ消えて2つに分かれる。メモは両方に残る。
   2. マーカーを終えて選択肢①をタップすると、取り消し線が付く。
   3. ⋯ →「PDFに出力」→ 印刷画面で「PDF として保存」。マーカーの色が付いた A4 縦書きのページと、メモの一覧ページが出る。

### 自動テスト

```sh
node tests/e2e.mjs   # Playwright（Chromium）で、Android 相当のタッチ操作を流す
```

画面の画像と出力した PDF は `tests/out/` に保存されます。
