# PIT WALL 26 — F1風ピットウォール戦略シミュレーター

`index.html` をブラウザ（スマホ可）で開くだけで遊べます。ビルド不要。

- 2026年カレンダー全23戦（バーレーンGPはセパン開催、サウジは開催なし）
- チームを選び、2台のスタートタイヤ／ピット指示／ドライビングモードだけを操作
- 1x〜500x の倍速。イベント（雨・SC・タイヤ限界・無線など）で自動的に等倍へ
- 天候：各サーキットの過去の本番レースの天候からランダムに1年を採用
- タイヤ摩耗・崖、燃料、ダーティエア、2026オーバーテイクモード、ERS自動デプロイ
- チーム別トラブル率・ドライバー性格によるクラッシュ率（雨で上昇）→ 程度に応じて SC / VSC / 黄旗
- 2種類のドライコンパウンド義務（違反は失格）
- ドライバー無線（音声読み上げ ON/OFF）、表彰式、ランキング（ブラウザに保存）

3D表示（three.js）：俯瞰／ヘリ／中継／1台追尾の4カメラ。タイミングタワーの行をタップするとそのマシンを追います。
コース形状は実コースの座標データ（bacinger/f1-circuits, MIT, `LICENSE-circuits.md`）から生成。高低差は推定値です。
チーム名・ドライバー名は実在の名前を1文字程度変えたものです。
強さ・スターティンググリッド・リタイア率は2026年の実データ（第1〜20戦、Jolpica F1 API）から生成しています（`data.js` の `STRENGTH_POINTS` / `AVG_GRID` / `REAL_GRIDS` / `DNF_RATE_2026`）。未開催のラスベガス・カタール・アブダビは予選シミュレーション。ゲーム内ランキングは0ポイントから始まります。`data.js` を書き換えれば名前・能力値・ポイント・天候データを自由に変更できます。
